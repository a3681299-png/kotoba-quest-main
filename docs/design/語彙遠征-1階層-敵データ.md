## 1. 1階層のテーマ

新モデル（全文実行＋コスト＋使用回数）を踏まえ、**1階層＝「コスト経済とDPSトレードオフの習得」**。
- 使える文は **2文**、エナジー上限は 3〜4（`戦闘システム.md` の成長カーブ）。
- 「回復」「コスト回復」「攻撃の使い分け（通常／弱／防御）」で、**限られたコストで勝ち筋を作る**ことを教える。
- ※当初「1階層＝条件分岐」としていたが、新モデルでは**まず資源管理を教える層**に再定義。条件分岐は
  「無駄撃ち回避」として2階層以降で本格化。

### エンジン対応（既存／新規）
**✅ 既存で足りる**
- 通常攻撃＝`attack` ／ 回復＝`heal` ／ 防御＝`guard`

**🔶 新規が要る**
- **弱攻撃**（低コスト・低威力、2回で通常1回よりDPS上）
- **コスト回復**（エナジーを回復する専用行動）
- **コスト／使用回数／エナジー**（戦闘全体のシステム。`戦闘システム.md`）
- 敵の**強攻撃**／**疲労**（1ターン動けない）／**怯み**（通常攻撃でひるむ）

## 2. 敵データ（1-1 〜 1-4）

各敵は `EnemyDefinition`（`src/wordQuest/types.ts`）に対応。数値は**仮**（HP引継ぎ前提で要調整）。

### 1-1 目覚めの的（チュートリアル：コストと回復）
- **id**: `waking-target`　**icon**: 「的」　**accent**: `#7a9ac4`　**isBoss**: false
- **epithet**: ただ殴ってくるもの
- **maxHp**: 12　**basePower**: 3　**initialStatuses**: `[]`
- **プレイヤーができる行動**: 攻撃・回復・コスト回復 のみ（この3枚でチュートリアル）
- **敵の挙動**: 攻撃のみ。**2ターンに1回攻撃 or 毎ターン攻撃**（テンポは要調整）。
- **設計の狙い**:
  - **回復を使わないと倒し切れない**難度にする。＝殴り合いだけだと自分が先に落ちる。
  - **回復量 > 敵の攻撃ダメージ**でないと回復の意味が無いので、`heal` は敵1発ぶんより高く設定。
  - コストが尽きるので、途中で**コスト回復**を挟む必要がある＝コスト経済の体験。
- **solutionHints**:
  - `target-basic`（basic / 削り切る）: `requiresActions: ["attack"]` / bonus 0
  - `target-sustain`（special / 回復で耐える）: `requiresActions: ["heal","attack"]` / bonus 2
- **rewardPool**: `["弱攻撃（新規カード）"]`　← 1-2 で使う
- **チュートリアル**: 攻撃→回復→コスト回復の順にスロットをハイライト＋他をグレースケールで誘導。

### 1-2 二拍の案山子（DPSとコストの二択）
- **id**: `two-beat-scarecrow`　**icon**: 「案」　**accent**: `#c4a05b`　**isBoss**: false
- **epithet**: 通常攻撃でひるむもの
- **maxHp**: 14　**basePower**: 3　**initialStatuses**: `[]`
- **前提**: プレイヤーは**通常攻撃**を所持。**1-1クリアで弱攻撃を獲得**済み。
- **2文＋コストの制約で実質2択**：
  - **A：通常攻撃 ＋ 防御**（安全だがDPS低め。通常攻撃で敵が怯む）
  - **B：弱攻撃 ×2**（DPS高いが無防備。通常1回より弱2回が総ダメージ上）
- **敵の挙動**: 攻撃。**通常攻撃を受けると怯む**（＝その隙に手数が稼げる／被弾を減らせる）。
- **狙い**:
  - **A は安全・低速、B は高速・低耐久**というトレードオフを体感。
  - 弱2連ぶっ放しでも一応勝てるが**残HPが少ない状態でクリア**（次戦に響く＝HP引継ぎ）。
  - 通常攻撃ぶっ放しは、敵の行動ダメージに削り負けて**負ける**（DPS不足）。
  - → 「怯ませる通常」と「削る弱」を**交互**に使うのが最適、と気づかせる。
- **solutionHints**:
  - `scare-basic`（basic / 押し切る）: `requiresActions: ["弱攻撃"]` / bonus 0
  - `scare-tempo`（mastery / 怯ませて捌く）: `requiresActions: ["attack","弱攻撃"]` / bonus 3
- **rewardPool**: （防御やコスト効率を上げる語彙など。要決定）

### 1-3 溜め疲れの巨像（バーストを活かす）
- **id**: `weary-colossus`　**icon**: 「疲」　**accent**: `#b5735b`　**isBoss**: false
- **epithet**: 強打の後に息切れするもの
- **maxHp**: 16　**basePower**: 2（強攻撃は大）　**initialStatuses**: `[]`
- **敵の挙動**: **強攻撃**を放つ → **疲労状態（1ターン動けない）**。**1ターン周期・2ターン周期**を織り交ぜる。
- **狙い**: 敵の**疲労（動けない）ターン**に、1-2で覚えた**弱攻撃×2のバースト**を叩き込む。
  漫然と殴ると強攻撃で削られる＝**行動の読みと集中攻撃**を要求。
- **solutionHints**:
  - `colossus-basic`（basic / 耐えて削る）: `requiresActions: ["attack","heal"]` / bonus 0
  - `colossus-burst`（mastery / 隙にバースト）: `requiresActions: ["弱攻撃"]` / `requiresStatuses: []` / bonus 3
    ※「疲労中に弱×2」を評価できるよう、疲労状態を条件化する余地あり（→ 2階層の `ためている時` と接続）
- **rewardPool**: （バースト補助・コスト回復強化など。要決定）

### 1-4 二面の門番（1階層ボス：総合）
- **id**: `twofold-warden`　**icon**: 「門」　**accent**: `#8a6db5`　**isBoss**: true
- **epithet**: 通常と強打を繰り返す番人
- **maxHp**: 20　**basePower**: 3（強攻撃は大）　**initialStatuses**: `[]`
- **敵の挙動**: **攻撃 と 強攻撃 を繰り返す**。
- **狙い**: これまでの学び（回復で耐える／通常で怯ませる／弱2連バースト／コスト回復のタイミング）を
  **総動員**すれば勝てる。1階層の総まとめ。
- **solutionHints**:
  - `warden-basic`（basic / 押し切る）: `requiresActions: ["attack"]` / bonus 0
  - `warden-tempo`（special / 怯みと回復で捌く）: `requiresActions: ["attack","heal"]` / bonus 2
  - `warden-master`（mastery / 隙にバースト）: `requiresActions: ["弱攻撃","heal"]` / bonus 4
- **rewardPool**: 2階層への布石（`guard`／`counter`／`condition.player_attacked` など＝2階層の先制対策の下地）

## 3. この階層で扱うカード（すべて動詞スロット）

- 攻撃（通常）＝`attack`（✅既存）
- 回復＝`heal`（✅既存）
- 防御＝`guard`（✅既存）
- **弱攻撃**（低コスト・低威力）＝🔶新規（1-1報酬で獲得）
- **コスト回復**＝🔶新規

## 4. 未確定・要相談（オーナー kobashikawa 確認事項）

- **数値バランス**：各攻撃/回復の威力・コスト・使用回数、敵HP/威力、回復＞敵ダメージの具体値。
- **弱攻撃のDPS設計**：「弱×2 > 通常×1」を成立させるコスト/威力比。
- **怯み（flinch）**：通常攻撃で敵の次行動をどう止める/遅らせるか（スキップ？威力減？）。
- **疲労（fatigue）**：敵が1ターン動けない状態の付与条件（強攻撃後？周期？）。
- **疲労を条件語にするか**：1-3で「疲労中に弱2連」を条件分岐で書かせるなら、2階層の設計と接続。
