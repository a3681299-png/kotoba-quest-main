## 1. 2階層のテーマ

- **テーマ：条件を活かす特殊カード＋それを活かすギミック（敵の先制行動など）。**
- リーダー案の位置づけ：1層＝シンプルな攻撃 → **2層＝条件・特殊カードを追加し、敵のギミック（先制等）で活かす** → 3層＝コストのやり繰り。
- 1層で覚えたコスト感を前提に、**「今の状況に合った文だけ発動＝無駄撃ちを避ける」**形で条件（分岐）を本格導入する。
- コストの重み：2層は**中**（特殊カードは重め＝どれを撃つか選ばせる）。

---

## 2. 欲しいギミック（要望リスト）

- **敵の先制攻撃**：敵がこちらより先に動くターンがある。守る／受けの判断を迫る。
- **ため＋テレグラフ**：敵が1ターン溜め → 次ターンに大打撃。溜めを見て対応させる。
- **疲労（隙）**：強攻撃の後などに敵が1ターン動けない。そこにバーストを差し込ませる。
- **前後移動**：敵が前後に動く。前＝近接が有効／後＝遠距離や回復が有効、と使い分けさせる。
- **反撃を誘う挙動**：敵が攻撃してきた“後”に隙ができ、反撃（counter）が通りやすい。
- **状態を読ませる**：敵の状態（ためている／前にいる 等）を条件カードで読ませて、対応を書かせる。

## 3. 欲しいカード（特殊カード候補）

**条件カード（どんな時）**
- 「攻撃された時」＝ `condition.player_attacked`（✅既存）
- 「ためている時」＝ `condition.enemy_charging`（🔶新規）
- 「（敵が）前にいる時 / 後ろにいる時」＝ 位置条件（🔶新規）

**動詞カード（なにする）**
- 「守る」＝ `action.guard`（✅既存）／「反撃」＝ `action.counter`（✅既存）／「止める」＝ `action.stop`（✅既存）
- 「遠距離攻撃」（後ろの敵に有効）＝（🔶新規）
- 「回復」＝ `action.heal`（✅既存、前後移動の“後ろ”対応で活用）

## 4. エンジン対応（崩れ防止のため箇条書き）

**✅ 既存の部品で足りるもの**
- `action.guard`（守る）… 次の被害を軽減。先制対策の基本
- `action.counter`（反撃）… `player.statuses` に `attacked` があると全力。先制と好相性
- `condition.player_attacked`（攻撃された時）… 反撃分岐の条件
- `condition.player_hurt`（Max以下の時）… 回復分岐
- `connector.after`（〜してから）… 前の文が実行された後だけ通す
- `enraged`（強化）状態・`repeat-action` リアクション … ボスの気性表現に流用

**🔶 新規が要るもの**
- 敵の先制攻撃（敵がプレイヤーより先に動く）… 現状は敵＝ターン終わりに行動。**手番順の変更が要る**
- `charging`（ため）状態＋テレグラフ（1ターン溜め→次ターン大打撃）… 新しい `EnemyStatus` と挙動
- `condition.enemy_charging`（ためている時）… 溜めを読ませる条件語
- 位置（前後）状態＋「前/後にいる時」条件、遠距離攻撃 … 前後移動ギミック用

→ **新規は「先制」「ため状態＋条件」「前後＋遠距離」あたり**。守る/反撃/攻撃された時/〜してから は既存で成立。
