## 1. 2階層のテーマと教える概念

- **テーマ：敵が「先制／タイミング」で動く。** 1階層で覚えた条件分岐を使い、
  **敵の行動を先読みして「守る・反撃・溜め対応」を条件で組む**ことを教える。
- HPは1階層から**引継ぎ**（既存仕様どおり）。ステージ＝敵1体、4ステージ＝4体（4体目が階層ボス）。
- 学びの流れ：先制を知る → 反撃のタイミング → 溜め（テレグラフ）を読む → 複合（if/elif/else）。

## 2. エンジン対応表（既存で足りる部品 / 新規が要る部品）

| 使う要素 | 状態 | 補足 |
|---|---|---|
| `action.guard`（守る）| ✅ 既存 | 次の被害を軽減。先制対策の基本 |
| `action.counter`（反撃）| ✅ 既存 | `player.statuses` に `attacked` があると全力。先制と好相性 |
| `condition.player_attacked`（攻撃された時）| ✅ 既存 | 反撃分岐の条件 |
| `condition.player_hurt`（Max以下の時）| ✅ 既存 | 回復分岐 |
| `connector.after`（〜してから）| ✅ 既存 | 前の文が実行された後だけ通す |
| `enraged`（強化）状態・`repeat-action` リアクション | ✅ 既存 | ボスの気性表現に流用 |
| **敵の先制攻撃（敵がプレイヤーより先に動く）** | 🔶 新規 | 現状は敵＝ターン終わりに行動。**手番順の変更が要る** |
| **`charging`（ため）状態＋テレグラフ（1ターン溜め→次ターン大打撃）** | 🔶 新規 | 新しい `EnemyStatus` と挙動 |
| **`condition.enemy_charging`（敵がためている時）** | 🔶 新規 | 溜めを読ませる条件語 |

→ **新規は「敵の先制」「ため状態＋その条件」の3点だけ**。他は既存の部品で成立します。

## 3. 敵データ（2-1 〜 2-4）

各敵は `EnemyDefinition` に対応（`id / name / epithet / description / readingClue / maxHp / basePower /
initialStatuses / reactions / solutionHints / rewardPool / icon / accent / isBoss`）。

### 2-1 触れの衛兵（チュートリアル：先制を知る）
- **id**: `sentry-herald`　**icon**: 「哨」　**accent**: `#7aa0c4`　**isBoss**: false
- **epithet**: 先に動く見張り
- **maxHp**: 10　**basePower**: 2　**initialStatuses**: `[]`
- **description**: この階層の敵は、こちらが動く前に一手を差し込んでくる。衛兵の槍は軽いが速い。
- **readingClue**: 「私は先に動く。だが軽い一打だ。身構えれば、痛みはほとんど残らない。」
- **挙動**: **毎ターン先制**で小攻撃（新規：先制）。それ以外の特殊はなし。
- **reactions**: なし
- **solutionHints**:
  - `herald-basic`（basic / 押し返す）: `requiresActions: ["attack"]` / `requiresStatuses: []` / bonus 0
  - `herald-guard`（special / 先んじて守る）: `requiresActions: ["guard","attack"]` / `requiresStatuses: []` / bonus 2
- **rewardPool**: `["action.guard", "condition.player_attacked"]`
- **教えたいこと / チュートリアル**:
  - 「**この階層から敵が先に動く**」を注釈で明示。
  - 「守る」スロットをハイライト＋他をグレースケールで、`自分が / いつでも / なら / 守る` を組ませる。
  - 想定作戦文：`自分が｜いつでも｜なら｜守る` ＋ `自分が｜いつでも｜なら｜攻撃する`

### 2-2 誘いの牙（反撃のタイミング）
- **id**: `luring-fang`　**icon**: 「牙」　**accent**: `#c47a5b`　**isBoss**: false
- **epithet**: 攻撃の後に隙を見せるもの
- **maxHp**: 12　**basePower**: 3　**initialStatuses**: `[]`
- **description**: 大きく踏み込んで噛みつくが、その直後は体勢が崩れる。受けてから返すのが速い。
- **readingClue**: 「先に牙を入れる。だが噛んだ後は無防備だ。痛みを受けた者だけが、その隙を突ける。」
- **挙動**: **先制で強めの一撃**。攻撃した次は隙（＝反撃が通りやすい）。
- **reactions**:
  - `fang-open-after-bite`：`trigger: { kind: "after-action", action: "counter" }` →
    `effects: [{ kind: "add-enemy-status", status: "exposed" }]` / log「反撃を受けた牙が体勢を崩した。」
- **solutionHints**:
  - `fang-basic`（basic / 撃ち合う）: `requiresActions: ["attack"]` / `[]` / bonus 0
  - `fang-counter`（mastery / 受けて返す）: `requiresActions: ["counter"]` / `requiresStatuses: ["exposed"]` / bonus 3
- **rewardPool**: `["action.counter", "connector.after"]`
- **教えたいこと**:
  - **`condition.player_attacked`（攻撃された時）→ `counter`（反撃）** の分岐。先制を逆手に取る。
  - 想定作戦文：`自分が｜攻撃された時｜なら｜反撃する` ＋ `自分が｜いつでも｜なら｜攻撃する`

### 2-3 溜め撃ちの砲手（テレグラフを読む）※新規「ため」状態
- **id**: `charging-gunner`　**icon**: 「砲」　**accent**: `#b58a3c`　**isBoss**: false
- **epithet**: 一拍おいて撃つもの
- **maxHp**: 13　**basePower**: 2（溜め撃ちは大）　**initialStatuses**: `[]`
- **description**: 一度身を沈めて力を溜め、次の手番で大きな一撃を放つ。溜めている隙は動きが鈍い。
- **readingClue**: 「私は溜めてから撃つ。溜めの拍を見抜き、その時に備えよ。あるいは動きを止めてしまえ。」
- **挙動**（新規テレグラフ）: 1ターン目 `charging` 付与（溜め）→ 2ターン目 大ダメージ→解除、を繰り返す。
- **reactions**:
  - `gunner-vent`：`trigger: { kind: "after-action", action: "stop" }` →
    `effects: [{ kind: "remove-enemy-status", status: "charging" }]` / log「止められて溜めが霧散した。」
- **solutionHints**:
  - `gunner-basic`（basic / 削り切る）: `requiresActions: ["attack"]` / `[]` / bonus 0
  - `gunner-read`（mastery / 溜めを読む）: `requiresActions: ["guard"]`（または `["stop"]`）/
    `requiresStatuses: []` / bonus 3　※「ためている時に守る／止める」で被弾ゼロを狙う
- **rewardPool**: `["condition.enemy_charging", "action.stop"]`（`enemy_charging` は新規語彙）
- **教えたいこと**:
  - **`condition.enemy_charging`（ためている時）→ `guard`／`stop`** で先読み対応。
  - 想定作戦文：`自分が｜敵がためている時｜なら｜守る` ＋ `自分が｜いつでも｜なら｜攻撃する`

### 2-4 二拍子の巨兵（2階層ボス）
- **id**: `two-beat-golem`　**icon**: 「巨」　**accent**: `#8a6db5`　**isBoss**: true
- **epithet**: 先制と溜めを繰り返す番人
- **maxHp**: 20　**basePower**: 3（溜め撃ちは大）　**initialStatuses**: `[]`
- **description**: 奇数の拍で速い先制、偶数の拍で溜めてからの一撃。二つの拍を読み分けねば押し切られる。
- **readingClue**: 「速い拍と、溜める拍。二つを見分けよ。守る時、返す時、攻める時——それぞれに文を。」
- **挙動**: 奇数ターン＝先制小攻撃／偶数ターン＝`charging`→次で大攻撃。HP半分以下で `enraged`（威力+1）。
- **reactions**:
  - `golem-enrage`：`trigger: { kind: "repeat-action", }`（例）→ `add-enemy-power +1`（気性表現。要調整）
- **solutionHints**:
  - `golem-basic`（basic / 押し切る）: `requiresActions: ["attack"]` / `[]` / bonus 0
  - `golem-read`（special / 拍を読む）: `requiresActions: ["guard","counter"]` / `requiresStatuses: []` / bonus 2
  - `golem-master`（mastery / 三文で捌く）: `requiresActions: ["guard","counter","attack"]` / `[]` / bonus 4
- **rewardPool**: 次階層への布石（例）`["modifier.twice", "action.heal"]`
- **教えたいこと（if / elif / else の複合）**:
  1. `自分が｜敵がためている時｜なら｜守る`
  2. `自分が｜攻撃された時｜なら｜反撃する`
  3. `自分が｜いつでも｜なら｜攻撃する`
  - 上から評価され、**状態に一致した1文だけ**が実質発火する＝排他条件で分岐が選ばれる（＝1階層で学んだ形の総まとめ）。

## 5. 未確定・要相談メモ

- **先制のUI表現**：敵が先に動くことを、手番表示やアニメでどう伝えるか（kobashikawa 領域）。
- **`charging` の見せ方**：敵に「溜め中」バッジ＋readingClue で予告。何ターン溜めるか（1ターン想定）。
- **数値（HP／威力）は仮**。HP引継ぎ前提なので、2階層開始時の平均残HPを見て再調整が必要。
- **ボスの `enraged` 条件**：現エンジンの `repeat-action` では素直に「HP半分で怒る」を表現しづらい。
  HP割合トリガーを足すか、既存リアクションで近似するか要検討。
- **報酬語彙の割り当て**は、3階層（回数制限・行動連動）で何を教えるかと合わせて最終決定。
