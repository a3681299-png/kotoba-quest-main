## 1. ログイン機能

### セットアップ
- Firebase 設定を `.env` に配置してログインを有効化。
  - ※ `.env` は `.gitignore` 済み。各自 `env` ファイルをもらって同じ場所に置く必要あり。
  - ※ **メール/パスワードは Firebase コンソール側で有効化が必要**（Authentication → Sign-in method → メール/パスワード）。Google ログインは動作確認済み。

### ログイン画面（`src/components/AuthScreen.tsx` / `src/styles/auth.css`）
- ログイン画面と新規登録画面を **タブで明確に区別**（サブタイトルもモードで変化）。
- 新規登録モードは **カードの枠色を変更**して視覚的に区別。
- 新規登録時のみ **「パスワード（確認）」欄**を追加（打ち間違い防止）。
- 認証エラーの原因が分かるよう **エラーコードを表示するよう改善**（`auth/operation-not-allowed` などに個別メッセージ）。
- **【不具合修正】** 新規登録でエラー表示時にスクロールできず Google ログインボタンが隠れる問題を修正（中央寄せを scroll-safe な `margin:auto` 方式へ変更）。
- タブ追加に伴い、重複していた画面下部の「新規登録はこちら / ログインはこちら」リンクを削除。

## 2. モード選択画面（新規）

ログイン直後にいきなりゲームへ入らず、遊び方を選ぶ画面を追加。

- 新規コンポーネント `src/components/ModeSelectScreen.tsx` / `src/styles/mode-select.css`。
- カード2枚：「カードモード（条件分岐をカードで学ぶ）」「組み合わせモード（語彙遠征）」。
- `App.tsx` のルーティングにゲートを追加：ログイン後、カードモード未選択なら本画面を表示。
  - カードモード選択 → 既存のバトル画面へ。
  - 組み合わせモード選択 → 既存の語彙遠征（`?mode=reading-loop`）へ。
- ゲーム中は左上に「◀ モード選択」ボタン（ログアウトの下）を追加し、いつでも選択画面へ戻れる。
- **既存のゲーム画面（BattleScreen / WordQuest）の中身は変更していない**（導線＝App.tsx とルーティングのみ）。
- モックにあった誤字を修正：「か組み合わせモード」→「組み合わせモード」、「日本で学ぼう」→「日本語で学ぼう」。

## 3. 語彙遠征（WordQuest）— 不具合修正のみ

> UX 改善案（実行ボタンの点滅・エラー箇所の強調）は他担当の領域のため、
> コードには入れず `提案書.md` に提案として記載しています。

### 【不具合修正】カーソルが必ずスロット2へ戻る
- 現象: 語彙を置くと、作戦文が完成した後もカーソルが必ず「どんな時（スロット2 / condition）」へ戻ってしまう。
- 原因: `src/wordQuest/grammar.ts` の `getNextEmptySlot` が、全スロット充足後のフォールバックで `"condition"` を返していた。
- 修正: 完成後は `null` を返すようにし、`WordQuestRunScreen.tsx` の `placeWord` で `null` のときはカーソルを動かさないよう変更。
- 変更ファイル: `src/wordQuest/grammar.ts` / `src/features/word-quest/WordQuestRunScreen.tsx`
- 確認: `tsc` 型チェック通過 / `wordQuest` 単体テスト 11 件通過。
